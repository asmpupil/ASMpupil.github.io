以下是对各类数的总结，以及2、3、5倍数的判断方法

各类数的含义及包含的数

类别 包含什么数 是什么样的数
自然数 0, 1, 2, 3, … 表示物体个数的数，通常指非负整数（部分定义不含0，但现行教材多包含0）。
整数 …, -3, -2, -1, 0, 1, 2, 3, … 正整数、0和负整数的统称，没有小数部分。
分数 形如 a/b（b ≠ 0，a、b为整数）的数 可以表示整体的一部分，包括真分数、假分数、带分数。
小数 如0.1, 2.33, 3.1415… 十进制表示的另一种形式，分为有限小数、无限循环小数和无限不循环小数（后两者常见于无理数）。
百分数 形如 a%（a为任意实数）的数 分母固定为100的分数，用于表示比例或占有率。
质数 2, 3, 5, 7, 11, … 大于1的自然数，且只有1和本身两个因数。
合数 4, 6, 8, 9, 10, … 大于1的自然数，除了1和本身还有其他因数（注意：1既不是质数也不是合数）。
奇数 …, -5, -3, -1, 1, 3, 5, … 不能被2整除的整数，形式为 2k+1（k为整数）。
偶数 …, -4, -2, 0, 2, 4, … 能被2整除的整数，形式为 2k（k为整数）。
因数 如12的因数有1,2,3,4,6,12 整数a除以整数b（b ≠ 0）的商是整数，则b是a的因数（通常讨论正整数）。
倍数 如3的倍数有3,6,9,12,… 整数a能被整数b整除，则a是b的倍数（通常指非零整数倍）。
正数 所有大于0的数：1, 0.5, 2/3, 100%… 比0大的数，包括正整数、正分数、正小数、正无理数等。
负数 所有小于0的数：-1, -0.2, -4/5… 比0小的数，在正数前加负号“-”表示。
注意：质数、合数、奇数、偶数通常在自然数（或整数）范围内讨论；因数、倍数一般指非零整数；分数、小数、百分数本质都是实数的不同表示形式，正负数则覆盖所有非零实数。

2、3、5的倍数判断方法

  • 2的倍数：个位数字是 0、2、4、6、8 的整数。
    例如：128（个位8）是2的倍数；129（个位9）不是。
  • 3的倍数：各位数字之和能被 3 整除的整数。
    例如：123 → 1+2+3=6，6÷3=2，所以123是3的倍数；124 → 1+2+4=7，7不能被3整除，所以不是。
  • 5的倍数：个位数字是 0 或 5 的整数。
    例如：145（个位5）是5的倍数；140（个位0）也是；142（个位2）不是。

这些方法适用于所有整数（包括负整数，只需看绝对值部分）。
